# Legal notices

Each independently published package retains the license and copyright notices
required by the code it contains. Those notices live beside the package in
`packages/<name>/LICENSE` and are included by the existing package packing
workflow.

This repository is the canonical implementation source for its packages.
Signalridge owns the package manifests, entrypoints, runtime behavior, tests,
and release metadata. Local divergence from an upstream project is maintained in
the package source and its changelog.

The following packages receive the most substantial local maintenance and
therefore keep package-local behavior notes: `pi-subagents`, `pi-workflows`,
`pi-goal`, `pi-statusline`, `pi-input-history`, `pi-input-prefix`,
`pi-welcome`, `pi-herdr-state`, and `pi-gpt-fast`.
